Maximum time in milliseconds to wait for the applied resources to become ready after they are written to the cluster.

The default value 0 means no waiting at all: the step succeeds as soon as the write API calls succeed, which is the historical behavior. Set it to a positive value to make the step poll the resource statuses and fail the build when a resource does not become ready in time, or reaches a terminal failure (for example a Job with the BackoffLimitExceeded condition, or a Deployment with ProgressDeadlineExceeded).

The waiting is skipped entirely when the delete option is enabled.
